# Dijksra Algorithm

> This is a greedy algorithm that is used to find the most optimal path

## Explanation

Firstly, this algorithm takes in a graph made up using an array of nodes. It initilises them and allow them to run in the algorithm

This algorithm uses the data structure Minheap to store the nodes that it has discovered and tries to find the lowest cost way to reach the destination

This algorithm is like a modified BFS that takes weight into consideration when createing a path way.
